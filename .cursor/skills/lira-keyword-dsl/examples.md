# Skill trial prompts

Use these after loading `lira-keyword-dsl`:

1. Generate a legal `export abstract class` with one `abstract method` and show IR.
2. Classify: `define method greet` at module scope.
3. Normalize `import a, b, c as x from "pkg"` and explain alias binding.
4. Review `define class User` followed by unindented `define method getName` — siblings or nested?
5. Reject or accept `import default from "pkg" as x` with a rule citation.
